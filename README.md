# Silent Signals – Student Routine Analysis

## Project Description
Silent Signals is a Data Analytics and Visualization (DAV) project that analyzes students' daily routines and lifestyle patterns using Python and Pandas.

## Objectives
- Analyze students' daily routines.
- Identify patterns in sleep, screen time, and study hours.
- Clean missing data using the median method.
- Prepare data for visualization in Power BI.

## Technologies Used
- Python
- Pandas
- NumPy
- Microsoft Power BI
- CSV Dataset

## Dataset
The project contains 310 records for 10 students during January 2026. It includes sleep hours, screen time, study hours, physical activity, attendance, and assignment count.

## Data Processing
- Data generation
- Missing value detection
- Data cleaning
- Category encoding and decoding
- CSV file export

## Project Files
- `Silent_Signals_Raw_10Students.csv` – Original dataset
- `Silent_Signals_Cleaned_10Students.csv` – Cleaned dataset
- Python source code – Data generation and preprocessing

## Future Scope
An interactive Power BI dashboard and advanced data analysis can be added in the future.
